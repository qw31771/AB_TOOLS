# AB Tools 项目规范

你正在为 **AB Tools**（Maya 通用工具插件）编写代码。以下规范必须严格遵守。

## ⚠️ 最高优先级：规则自维护

1. **严格遵守**：本文档中的所有规范都是强制性约束，AI 必须严格遵守，不得有任何例外。
2. **自维护机制**：当用户修改了 `CLAUDE.md`、本 SKILL.md 或项目中的任何规则文件时，AI 必须自动识别变更内容，并将新增或修改的规范同步更新到对应的规则文件中。规则文件维护者就是 AI 自身，不需要用户手动提醒。
3. **CLAUDE.md 归属**：`CLAUDE.md` 是本 skill 管辖的核心文件之一。AI 必须主动维护它，包括但不限于：
   - 目录结构变更时同步更新项目结构树
   - 新增/修改规范时同步到对应章节
   - 新增模块/文件时在结构树中补全条目
   - 描述信息过时（如位置、方向、命名）时自动修正

## 核心架构

项目遵循 **"安装 -> 引导 -> 逻辑 -> 表现"** 解耦架构：

| 层 | 文件 | 职责 |
|---|---|---|
| 安装 | `install.py` | 拖放安装，注入 sys.path |
| 引导 | `ab_tools/__init__.py` | 模块重载，提供 init/run 入口 |
| 逻辑 | `ab_tools/main.py` | 工具架创建、按钮注册、UI 路由 |
| 表现 | `ab_tools/ui/` | PySide2 界面实现 |

## 目录与文件约束

1. **禁止修改目录结构**：必须保持 `AB_TOOLS/` 根目录及子目录层级不变。
2. **增量原则**：允许增加新文件，**严禁减少或删除**现有框架文件。
3. **命名保护**：严禁对现有文件、类名、核心函数名进行重命名。
4. **模块化**：UI 逻辑严禁出现在 `main.py` 中；核心配置严禁硬编码在 `ui/` 脚本中。
5. **结构同步**：每次目录结构变化时，必须立即更新 `CLAUDE.md` 中的项目结构部分。

## 模块初始化规范

- 每个文件夹都必须有 `__init__.py`，用于提供外部调用内部模块的结构接口
- `__init__.py` **只能**包含：结构调用、固定变量定义、类型声明。**严禁**逻辑运算和复杂计算
- 所有逻辑运算在同文件夹下的其他专门文件中实现
- 外部代码**只能**通过 `__init__.py` 导入，严禁直接导入内部逻辑文件
- 当内部逻辑文件新增外部可调用的函数时，必须在 `__init__.py` 中相应添加导入
- `__init__.py` 中每个导出结构必须包含 docstring，说明：功能描述、参数类型、返回值类型

## 事件管理规范

- **统一入口**：所有自定义信号必须通过 `eventManager` 模块 (`from ab_tools import eventManager`)
- **单例模式**：`EventManager` 全局唯一实例
- **集中注册**：信号常量在 `eventManager/__init__.py` 定义，导入时自动执行 `_register_all_signals()`
- **新增信号**：在 `__init__.py` 中定义常量 → 加入 `_SIGNAL_REGISTRY` → 全局立即可用
- **线程安全**：事件管理器保证多线程安全使用
- **命名规范**：snake_case，前缀表示域（ui_/tool_/config_），过去式表示已完成（opened/closed），进行时表示进行中（opening/closing）
- **禁止**在项目其他地方创建自定义事件系统，所有模块间通信走事件管理器


## core 模块扩展规范

- **物理隔离**：`core/` 下每个功能模块独立为一个子目录
- **入口聚合**：新增模块后在 `core/__init__.py` 添加导入：`from . import xxx` + 更新 `__all__`
- **根接口提升**：需要对外暴露的模块，在 `ab_tools/__init__.py` 中 `from .core import xxx` 提升
- **统一调用**：外部统一 `from ab_tools import xxx`，`xxx.功能()` 调用
- **接口与逻辑分离**：每个子目录内 `__init__.py` 只做结构导入和常量定义

## 脚本格式规范

- 编码：`# -*- coding: utf-8 -*-`
- 环境：Python 3 (Maya 2022+)
- UI 库：仅限 `PySide2`（兼容 Maya 原生库）
- 路径处理：使用 `os.path` 动态获取，禁止绝对路径

## 配置分层规范

- **硬性规则：所有可配置数据（颜色、尺寸、字符串、样式等）必须放入 `config/` 模块，严禁在 UI 或业务代码中硬编码**
- `config_data.py`：仅存放物理路径计算、Maya API 原始值读取、基础数值定义
- `__init__.py (Config 类)`：将数据组装成逻辑对象
- **严禁**业务代码直接 `import config_data`，必须通过 `Config` 类访问
- **双层准则**：像素数值（宽/高/边距）→ `__init__.py`；路径算法/DPI/公式 → `config_data.py`
- **新增类型**：当 config 中无对应类型存放位置时，在 `__init__.py` 中新建 Class（如 `Theme` 存颜色），不得绕过 config
